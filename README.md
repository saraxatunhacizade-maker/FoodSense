# 🍴 FoodSense – AI-Powered Smart Menu Recommendation System

## Overview
FoodSense is a Business Analysis project that proposes an AI-powered restaurant recommendation system. The solution combines weather data, dietary preferences, allergens, and location to deliver personalized menu recommendations.

## Objectives
- Analyze business requirements
- Design the proposed solution
- Model business processes
- Define functional and non-functional requirements

## Deliverables
- Business Requirements
- Functional & Non-Functional Requirements
- BPMN Process Models
- ER Diagram
- Project Presentation
